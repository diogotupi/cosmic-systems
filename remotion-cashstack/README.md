# Remotion — Cash Stack demos

Vídeos promocionais do [The Cash Stack](https://www.thecashstack.com) gerados com Remotion.

## Composições

| ID | Descrição |
| --- | --- |
| `SettlingDemo` | Settling automático — mínimo de transferências |
| `InsigniasDemo` | Achievements eternos + insígnias temporárias |

## Desenvolvimento

```bash
cd remotion-cashstack
npm i
npm run dev
```

## Render

```bash
npm run render:settling
npm run render:insignias
```

Os MP4 gerados em `out/` devem ser copiados para `../site/videos/` para o carrossel do site Cosmic Systems.
